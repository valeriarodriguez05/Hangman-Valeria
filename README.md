🎮 Hangman WPF — Jeu du Pendu en C#
Un petit jeu du Pendu développé en C# avec WPF, incluant :

✔️ Interface graphique
✔️ Système de vies et visuels du pendu
✔️ Sons (clic, victoire, défaite)
✔️ Timer de 3 minutes
✔️ Clavier virtuel
✔️ Choix aléatoire de mots liés à l’informatique

🖼️ Fonctionnalités
📝 Jeu du Pendu complet
Un mot aléatoire est choisi au début de chaque partie.
Le joueur doit deviner le mot, lettre par lettre.
Les lettres déjà jouées sont désactivées (vert = correcte, rouge = incorrecte).

❤️ Gestion des vies
6 vies au départ.
À chaque erreur :
Le pendu se complète étape par étape
L’image des cœurs se met à jour

⏱️ Timer intégré
Chaque partie dure 3 minutes.
Le temps s’affiche sous le format MM:SS.
Si le temps expire → Game Over.

🔊 Effets sonores
Les sons inclus :
clic sur une lettre
victoire
défaite

🎨 Interface visuelle dynamique
Images du pendu selon l'état
Images des vies
Mise à jour du mot affiché avec * puis lettres découvertes
